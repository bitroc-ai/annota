# Svelte Functions

Svelte functions for working with annotations, layers, tools, and UI state.

## Overview

Annota provides a comprehensive set of Svelte functions for building annotation interfaces. Functions are organized into several categories:

## Annotation Functions

Access and manage annotations:

- **[annotations](/api/hooks/use-annotations)** - Get all annotations
- **[useAnnotation](/api/hooks/use-annotation)** - Get a specific annotation by ID
- **[selection](/api/hooks/use-selection)** - Get currently selected annotations
- **[useHover](/api/hooks/use-hover)** - Track hovered annotation
- **[useAnnotationDoubleClick](/api/hooks/use-annotation-double-click)** - Listen for double-click events

## Store & Instance Functions

Direct access to core instances:

- **[useAnnotationStore](/api/hooks/use-annotation-store)** - Direct annotation store access
- **[getAnnotator](/api/hooks/use-annotator)** - Get annotator instance
- **[viewer](/api/hooks/use-viewer)** - Get OpenSeadragon viewer instance

## Layer Management Functions

Manage annotation layers:

- **[layers](/api/hooks/use-layers)** - Get all layers
- **[useLayer](/api/hooks/use-layer)** - Get a specific layer
- **[layerManager](/api/hooks/use-layer-manager)** - Full layer CRUD operations
- **[useImageLayerVisibility](/api/hooks/use-image-layer-visibility)** - Control image layer visibility

## History & Undo/Redo Functions

Manage annotation history:

- **[history](/api/hooks/use-history)** - Full history management
- **[useCanUndo](/api/hooks/use-can-undo)** - Check if undo is available
- **[useCanRedo](/api/hooks/use-can-redo)** - Check if redo is available

## Tool Management Functions

Manage annotation tools:

- **[tool](/api/hooks/use-tool)** - Manage tool lifecycle
- **[pushToolCursor](/api/hooks/use-push-tool-cursor)** - Track push tool cursor

## UI & Interaction Functions

Manage UI state and user interactions:

- **[usePopup](/api/hooks/use-popup)** - Manage annotation popup state
- **[editing](/api/hooks/use-editing)** - Manage vertex editing mode
- **[contextMenu](/api/hooks/use-context-menu)** - Manage context menu state
- **[contextMenuBinding](/api/hooks/use-context-menu-binding)** - Auto-bind context menu events

## Quick Example

Here's a typical component using multiple functions:

```svelte
<script lang="ts">
  import {
    annotations,
    selection,
    layerManager,
    history,
    tool,
    PointTool,
  } from 'annota/svelte';
  import OpenSeadragon from 'openseadragon';

  interface Props {
    viewer: OpenSeadragon.Viewer | undefined;
  }

  let { viewer }: Props = $props();
  let currentTool = $state('point');

  const annotationsList = annotations();
  const selected = selection();
  const { layers, createLayer } = layerManager();
  const { canUndo, canRedo, undo, redo } = history();

  tool({
    viewer: () => viewer,
    handler: () => currentTool === 'point' ? new PointTool() : null,
    enabled: () => currentTool === 'point',
  });
</script>

<div>
  <!-- Toolbar -->
  <div class="toolbar">
    <button onclick={() => currentTool = 'pan'}>Pan</button>
    <button onclick={() => currentTool = 'point'}>Point</button>
    <button onclick={undo} disabled={!canUndo}>Undo</button>
    <button onclick={redo} disabled={!canRedo}>Redo</button>
  </div>

  <!-- Stats -->
  <div class="stats">
    <p>Total annotations: {annotationsList.length}</p>
    <p>Selected: {selected.length}</p>
    <p>Layers: {layers.length}</p>
  </div>
</div>
```

## Function Guidelines

### 1. Always Check for undefined

Many functions return `undefined` during initialization:

```svelte
<script lang="ts">
  import { getAnnotator, viewer } from 'annota/svelte';

  const getAnnotatorFn = getAnnotator();
  const viewerFn = viewer();

  // ✅ Good
  $effect(() => {
    const annotator = getAnnotatorFn();
    if (annotator) {
      annotator.addAnnotation(...);
    }
  });

  // ❌ Bad - may crash
  // getAnnotatorFn().addAnnotation(...);
</script>
```

### 2. Use Functions with Svelte Reactivity

Functions work with Svelte's reactivity system:

```svelte
<script lang="ts">
  import { annotations, selection } from 'annota/svelte';

  const annotationsList = annotations();
  const selected = selection();
</script>

<div>
  <p>Total: {annotationsList.length}</p>
  <p>Selected: {selected.length}</p>
</div>
```

### 3. Combine Functions for Complex Logic

Use multiple functions together for rich functionality:

```svelte
<script lang="ts">
  import { editing, selection, getAnnotator } from 'annota/svelte';
  import OpenSeadragon from 'openseadragon';

  interface Props {
    viewer: OpenSeadragon.Viewer | undefined;
  }

  let { viewer }: Props = $props();

  const editingState = editing();
  const selected = selection();
  const getAnnotatorFn = getAnnotator();

  $effect(() => {
    if (!viewer) return;

    const handleDoubleClick = () => {
      // Handle double-click logic
    };

    viewer.addHandler('canvas-double-click', handleDoubleClick);
    return () => viewer.removeHandler('canvas-double-click', handleDoubleClick);
  });
</script>
```
