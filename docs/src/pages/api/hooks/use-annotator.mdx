# getAnnotator

Get the Annota annotator instance for programmatic access.

## Signature

```typescript
function getAnnotator(): () => AnnotatorInstance | undefined;
```

## Returns

A function that returns the annotator instance, or `undefined` if not yet initialized.

## Example

```svelte
<script lang="ts">
  import { getAnnotator } from 'annota/svelte';

  const getAnnotatorFn = getAnnotator();

  function handleAddPoint() {
    const annotator = getAnnotatorFn();
    if (!annotator) return;

    annotator.addAnnotation({
      id: `point-${Date.now()}`,
      shape: {
        type: 'point',
        geometry: { x: 500, y: 500 },
        bounds: { minX: 500, minY: 500, maxX: 500, maxY: 500 },
      },
    });
  }

  function handleClearAll() {
    const annotator = getAnnotatorFn();
    annotator?.clearAnnotations();
  }
</script>

<div>
  <button onclick={handleAddPoint}>Add Point</button>
  <button onclick={handleClearAll}>Clear All</button>
</div>
```

## Accessing Internal State

```svelte
<script lang="ts">
  import { getAnnotator } from 'annota/svelte';

  const getAnnotatorFn = getAnnotator();

  $effect(() => {
    const annotator = getAnnotatorFn();
    if (!annotator) return;

    // Access the annotation store directly
    const allAnnotations = annotator.state.store.all();
    console.log('Total:', allAnnotations.length);
  });
</script>

<div>Total: {getAnnotatorFn()?.state.store.all().length ?? 0}</div>
```

## Usage Notes

- Provides access to all annotator methods (add, update, delete, etc.)
- Returns a function that may return `undefined` during initialization - always check before using
- See [Annotator Instance](/api/annotator) for complete API documentation
