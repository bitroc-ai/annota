## Prerequisites

Before installing Annota, ensure you have:

- **Node.js** 18 or higher
- **React** 18 or higher
- A package manager (npm, pnpm, or yarn)

## Install Annota

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install annota openseadragon
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add annota openseadragon
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add annota openseadragon
    ```
  </TabItem>
</Tabs>

<Aside type="note">
  **OpenSeadragon** is a required peer dependency for viewport management and image display.
</Aside>

## TypeScript Support

Annota is written in TypeScript and includes full type definitions. For OpenSeadragon types:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install --save-dev @types/openseadragon
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add -D @types/openseadragon
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add -D @types/openseadragon
    ```
  </TabItem>
</Tabs>

## Import Styles

Import the required CSS in your app entry point:

```tsx
import "annota/dist/index.css";
```

Or in your global CSS:

```css
@import "annota/dist/index.css";
```

## Verify Installation

Create a simple test component:

```tsx
import { AnnotaProvider, AnnotaViewer, Annotator } from "annota";
import { useState } from "react";
import "annota/dist/index.css";

function TestViewer() {
  const [viewer, setViewer] = useState(null);

  return (
    <AnnotaProvider slideId="test">
      <div style={{ width: "800px", height: "600px" }}>
        <AnnotaViewer
          options={{
            tileSources: {
              type: "image",
              url: "https://picsum.photos/1920/1080",
            },
            prefixUrl: "https://cdn.jsdelivr.net/npm/openseadragon@4/build/openseadragon/images/",
          }}
          onViewerReady={setViewer}
        />
        <Annotator viewer={viewer} />
      </div>
    </AnnotaProvider>
  );
}
```

If you see an image viewer, Annota is installed correctly!
