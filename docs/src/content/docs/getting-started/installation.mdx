## Prerequisites

Before installing Annota, ensure you have:

- **Node.js** 18 or higher
- **React 18+ / 19+** OR **Svelte 5**
- A package manager (npm, pnpm, or yarn)

## Choose Your Framework {#react-vs-svelte}

Annota provides identical functionality for both React and Svelte. The only difference is the reactive API (hooks vs stores).

<Tabs>
  <TabItem label="React">
    ### React Installation

    React users get:
    - React hooks (`useAnnotator`, `useAnnotations`, `useTool`, etc.)
    - React components with JSX
    - Full TypeScript support
    - Optimized for React 18+ and React 19+

  </TabItem>
  <TabItem label="Svelte">
    ### Svelte Installation

    Svelte users get:
    - Svelte stores (`annotator()`, `annotations()`, `tool()`, etc.)
    - Svelte components with Svelte 5 runes
    - Full TypeScript support
    - Optimized for Svelte 5

  </TabItem>
</Tabs>

## Install Core Package {#install-core}

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install annota openseadragon
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add annota openseadragon
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add annota openseadragon
    ```
  </TabItem>
</Tabs>

<Aside type="note">
  **OpenSeadragon** is a required peer dependency for viewport management and image display.
</Aside>

## TypeScript Support {#typescript}

Annota is written in TypeScript and includes full type definitions. For OpenSeadragon types:

<Tabs>
  <TabItem label="npm">

    ```bash
    npm install --save-dev @types/openseadragon
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add -D @types/openseadragon
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add -D @types/openseadragon
    ```
  </TabItem>
</Tabs>

## Import Styles {#import-styles}

Import the required CSS in your app entry point:

**React:**
```tsx
import "annota/dist/index.css";
```

**Svelte:**
```svelte
<script>
  import "annota/dist/index.css";
</script>
```

Or in your global CSS:

```css
@import "annota/dist/index.css";
```

## Verify Installation {#verify}

### React Verification

Create a simple test component:

```tsx
import { AnnotaProvider, AnnotaViewer, Annotator } from "annota";
import { useState } from "react";
import "annota/dist/index.css";

function TestViewer() {
  const [viewer, setViewer] = useState(null);

  return (
    <AnnotaProvider>
      <div style={{ width: "800px", height: "600px" }}>
        <AnnotaViewer
          options={{
            tileSources: {
              type: "image",
              url: "https://picsum.photos/1920/1080",
            },
            prefixUrl: "https://cdn.jsdelivr.net/npm/openseadragon@4/build/openseadragon/images/",
          }}
          onViewerReady={setViewer}
        />
        <Annotator viewer={viewer} />
      </div>
    </AnnotaProvider>
  );
}
```

### Svelte Verification

Create a simple test component:

```svelte
<script>
  import { AnnotaProvider, AnnotaViewer, Annotator } from "annota/svelte";
  import "annota/dist/index.css";

  let viewer = $state(null);
</script>

<AnnotaProvider>
  <div style="width: 800px; height: 600px;">
    <AnnotaViewer
      options={{
        tileSources: {
          type: "image",
          url: "https://picsum.photos/1920/1080",
        },
        prefixUrl: "https://cdn.jsdelivr.net/npm/openseadragon@4/build/openseadragon/images/",
      }}
      onViewerReady={(v) => viewer = v}
    />
    {#if viewer}
      <Annotator {viewer} />
    {/if}
  </div>
</AnnotaProvider>
```

If you see an image viewer in either case, Annota is installed correctly!
