## Version History

### 1.0.0

Initial release with core features:

- **Components**: AnnotaProvider, AnnotaViewer, Annotator
- **Tools**: PointTool, RectangleTool, PolygonTool, PushTool, ContourTool
- **Hooks**: Full React hooks API
- **Layer System**: Multi-layer support with visibility and styling
- **Data Loaders**: H5, JSON, PGM support
- **Performance**: R-tree indexing, viewport culling, LOD rendering
