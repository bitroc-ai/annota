# Quick Start

Build your first annotation viewer in minutes with Annota.

## Minimal Example

Here's the simplest possible annotation viewer:

```svelte
<script lang="ts">
  import { AnnotaProvider, Viewer as AnnotaViewer, Annotator } from "annota/svelte";
  import type OpenSeadragon from "openseadragon";

  let viewer: OpenSeadragon.Viewer | undefined = $state(undefined);
</script>

<AnnotaProvider slideId="my-slide">
  <div style="width: 100vw; height: 100vh;">
    <AnnotaViewer
      options={{
        tileSources: "/path/to/image.dzi",
        prefixUrl:
          "https://cdn.jsdelivr.net/npm/openseadragon@4/build/openseadragon/images/",
      }}
      onViewerReady={(v) => viewer = v}
    />
    <Annotator viewer={viewer} />
  </div>
</AnnotaProvider>
```

That's it! You now have a working image viewer with annotation capabilities.

## Understanding the Code

Let's break down what each component does:

### 1. AnnotaProvider

```svelte
<AnnotaProvider slideId="my-slide">
```

The `AnnotaProvider` wraps your application and provides annotation context. The `slideId` prop identifies this slide's annotations (useful for multi-slide applications).

### 2. Viewer

```svelte
<Viewer
  options={{
    tileSources: "/path/to/image.dzi",
    prefixUrl: "...",
  }}
  onViewerReady={(v) => viewer = v}
/>
```

The `Viewer` component creates and manages the OpenSeadragon viewer. It accepts:

- `options`: OpenSeadragon configuration options
- `onViewerReady`: Callback when the viewer is initialized

### 3. Annotator

```svelte
<Annotator viewer={viewer} />
```

The `Annotator` component creates the annotation overlay layer. It must receive the OpenSeadragon viewer instance.

## Adding Annotation Tools

Let's add tools for creating annotations:

```svelte
<script lang="ts">
  import { AnnotaProvider, Viewer as AnnotaViewer, Annotator, tool } from "annota/svelte";
  import { PointTool, RectangleTool, PolygonTool } from "annota";
  import type OpenSeadragon from "openseadragon";

  let viewer: OpenSeadragon.Viewer | undefined = $state(undefined);
  let currentTool = $state("point");

  const tools = {
    point: new PointTool(),
    rectangle: new RectangleTool(),
    polygon: new PolygonTool(),
  };

  tool({
    viewer: () => viewer,
    handler: () => currentTool === "pan" ? null : tools[currentTool],
    enabled: () => currentTool !== "pan",
  });
</script>

<AnnotaProvider slideId="my-slide">
  <div style="width: 100vw; height: 100vh; position: relative;">
    <div style="position: absolute; top: 20px; left: 20px; z-index: 10;">
      <button onclick={() => currentTool = "point"}>Point</button>
      <button onclick={() => currentTool = "rectangle"}>Rectangle</button>
      <button onclick={() => currentTool = "polygon"}>Polygon</button>
      <button onclick={() => currentTool = "pan"}>Pan</button>
    </div>

    <AnnotaViewer
      options={{
        tileSources: "/path/to/image.dzi",
        prefixUrl:
          "https://cdn.jsdelivr.net/npm/openseadragon@4/build/openseadragon/images/",
      }}
      onViewerReady={(v) => viewer = v}
    />

    <Annotator viewer={viewer} />
  </div>
</AnnotaProvider>
```

Now you have a complete annotation interface with multiple tools!

## Accessing Annotations

Use functions to access and display annotations:

```svelte
<script lang="ts">
  import { annotations, selection } from "annota/svelte";

  const annotationsList = annotations();
  const selected = selection();
</script>

<div style="position: absolute; top: 20px; right: 20px; z-index: 10;">
  <h3>Annotations ({annotationsList.length})</h3>
  <ul>
    {#each annotationsList as ann (ann.id)}
      <li>
        {ann.shape.type}
        {selected.some((s) => s.id === ann.id) && " (selected)"}
      </li>
    {/each}
  </ul>
</div>
```

Add this component inside `AnnotaProvider`:

```svelte
<AnnotaProvider slideId="my-slide">
  <!-- ... other components ... -->
  <AnnotationList />
</AnnotaProvider>
```

## Full Example

Here's a complete, production-ready example:

```svelte
<script lang="ts">
  import {
    AnnotaProvider,
    Viewer as AnnotaViewer,
    Annotator,
    annotations,
    selection,
    tool,
    PointTool,
    RectangleTool,
    PolygonTool,
  } from "annota/svelte";
  import type OpenSeadragon from "openseadragon";

  let viewer: OpenSeadragon.Viewer | undefined = $state(undefined);
  let currentTool = $state("pan");

  const annotationsList = annotations();
  const selected = selection();

  // Tool instances
  const tools = {
    point: new PointTool(),
    rectangle: new RectangleTool(),
    polygon: new PolygonTool(),
  };

  // Activate the selected tool
  tool({
    viewer: () => viewer,
    handler: () => currentTool === "pan" ? null : tools[currentTool],
    enabled: () => currentTool !== "pan",
  });
</script>

<AnnotaProvider slideId="slide-001">
  <div style="width: 100vw; height: 100vh; position: relative;">
    <!-- Toolbar -->
    <div style="position: absolute; top: 20px; left: 20px; z-index: 10;">
      <button onclick={() => currentTool = "pan"}>Pan</button>
      <button onclick={() => currentTool = "point"}>Point</button>
      <button onclick={() => currentTool = "rectangle"}>Rectangle</button>
      <button onclick={() => currentTool = "polygon"}>Polygon</button>
    </div>

    <!-- Info panel -->
    <div style="position: absolute; top: 20px; right: 20px; z-index: 10;">
      <div>Annotations: {annotationsList.length}</div>
      <div>Selected: {selected.length}</div>
    </div>

    <!-- Viewer -->
    <AnnotaViewer
      options={{
        tileSources: "/path/to/image.dzi",
        prefixUrl:
          "https://cdn.jsdelivr.net/npm/openseadragon@4/build/openseadragon/images/",
        showNavigationControl: false,
      }}
      onViewerReady={(v) => viewer = v}
    />

    <!-- Annotation overlay -->
    <Annotator viewer={viewer} />
  </div>
</AnnotaProvider>
```

## Common Patterns

### Loading Existing Annotations

```svelte
<script lang="ts">
  import { getAnnotator } from "annota/svelte";

  const getAnnotatorFn = getAnnotator();

  $effect(() => {
    const annotator = getAnnotatorFn();
    if (!annotator) return;

    // Load annotations from your API
    fetch("/api/annotations/slide-001")
      .then((res) => res.json())
      .then((annotations) => {
        annotator.addAnnotations(annotations);
      });
  });
</script>
```

### Saving Annotations

```svelte
<script lang="ts">
  import { annotations } from "annota/svelte";

  const annotationsList = annotations();

  function handleSave() {
    fetch("/api/annotations/slide-001", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(annotationsList),
    });
  }
</script>

<button onclick={handleSave}>Save</button>
```

### Custom Styling

```svelte
<Annotator
  viewer={viewer}
  style={(annotation) => ({
    fill: annotation.properties?.type === "tumor" ? "#FF0000" : "#00FF00",
    fillOpacity: 0.3,
    stroke: "#FFFFFF",
    strokeWidth: 2,
  })}
/>
```

## Troubleshooting

### Annotations not appearing

Make sure:

1. The `Annotator` component receives a valid `viewer` prop
2. The `viewer` prop is updated when OpenSeadragon initializes
3. You're adding annotations after the annotator is ready

### Tools not working

Check that:

1. `tool` function receives a valid `viewer` function
2. The `enabled` function returns `true`
3. The tool handler is properly instantiated

### TypeScript errors

Ensure you have installed the type definitions:

```bash
npm install --save-dev @types/openseadragon
```
