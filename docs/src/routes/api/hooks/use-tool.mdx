# tool

Manage tool lifecycle and enable/disable annotation tools.

## Signature

```typescript
interface ToolOptions {
  viewer: () => OpenSeadragon.Viewer | undefined;
  handler: () => ToolHandler | null;
  enabled: () => boolean;
}

function tool(options: ToolOptions): void;
```

## Parameters

- `viewer` - A function that returns the OpenSeadragon viewer instance
- `handler` - A function that returns the tool handler instance (or null for pan mode)
- `enabled` - A function that returns whether the tool is enabled

## Example

```svelte
<script lang="ts">
  import { tool, PointTool, RectangleTool, PolygonTool } from 'annota/svelte';
  import type OpenSeadragon from 'openseadragon';

  interface Props {
    viewer: OpenSeadragon.Viewer | undefined;
  }

  let { viewer }: Props = $props();
  let currentTool = $state<string>('point');

  const tools = {
    point: new PointTool(),
    rectangle: new RectangleTool(),
    polygon: new PolygonTool(),
  };

  tool({
    viewer: () => viewer,
    handler: () => currentTool === 'pan' ? null : tools[currentTool],
    enabled: () => currentTool !== 'pan',
  });
</script>

<div class="toolbar">
  <button onclick={() => currentTool = 'pan'}>Pan</button>
  <button onclick={() => currentTool = 'point'}>Point</button>
  <button onclick={() => currentTool = 'rectangle'}>Rectangle</button>
  <button onclick={() => currentTool = 'polygon'}>Polygon</button>
</div>
```

## Usage Notes

- Automatically manages tool lifecycle (enable/disable/destroy)
- Pass a function returning `null` for handler to enable pan mode
- Tools are properly cleaned up when component unmounts
- All parameters are functions to ensure reactivity with Svelte's reactivity system
